# Stock Portfolio Performance Tracker

## Description

The Stock Portfolio Performance Tracker is a Python command-line application that helps users track stock investments, calculate portfolio value, and determine profit or loss.

The program uses an S&P 500 company dataset to validate stock ticker symbols and attempts to retrieve current stock prices through Yahoo Finance.

## Features

- Loads company symbols from `constituents.csv`
- Validates S&P 500 ticker symbols
- Accepts purchase prices and share quantities
- Retrieves current stock prices using Yahoo Finance when available
- Supports manual price entry when automatic lookup fails
- Calculates total invested capital
- Calculates current market value
- Calculates profit or loss and percentage return
- Displays a formatted portfolio summary
- Exports results to `portfolio_summary.csv`

## Technologies Used

- Python 3
- Built-in `csv` module
- File handling
- Dictionaries and sets
- Exception handling
- `yfinance` library

## Project Files

- `portfolio.py` — Main application
- `constituents.csv` — S&P 500 company information and ticker symbols
- `portfolio_summary.csv` — Sample portfolio output generated by the program

## Requirements

- Python 3
- Internet connection for online stock price lookup
- `yfinance` library

## Installation

Install the required library using:

```bash
python -m pip install yfinance
```

## How to Run

1. Open a terminal in the `Task2_Stock_Portfolio` folder.
2. Run:

```bash
python portfolio.py
```

3. Enter a stock ticker symbol, such as `AAPL`.
4. Enter your purchase price per share and number of shares.
5. Add more stocks if needed.
6. Type `DONE` to finish and display the summary.

If automatic price retrieval fails, the program asks for a current price manually.

## Calculations

- **Total Invested:** Purchase Price × Number of Shares
- **Current Value:** Current Price × Number of Shares
- **Profit/Loss:** Current Value − Total Invested
- **Gain/Loss (%):** (Profit/Loss ÷ Total Invested) × 100

## Dataset

The `constituents.csv` file contains S&P 500 company names and ticker symbols. It is used for symbol validation and does not contain stock prices.

## Output

The application displays portfolio performance in the terminal and generates `portfolio_summary.csv`, which can be opened using Excel or another spreadsheet application.
